# Cloud-Based Event Registration and Management System

## Project Description
The Cloud-Based Event Registration and Management System is a web application designed to simplify event creation, management, and online registration. Users can view upcoming events, check event details, and register online. Administrators can create, update, and manage events and participant information.

The project uses AWS cloud services to provide reliable hosting, secure data storage, and easy accessibility.

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Java, Spring Boot
- Database: MySQL
- Cloud Platform: Amazon Web Services (AWS)

## AWS Services
- Amazon EC2
- Amazon S3
- Amazon RDS
- AWS IAM
- Amazon CloudWatch
